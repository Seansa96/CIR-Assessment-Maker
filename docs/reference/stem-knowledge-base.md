# STEM Reference Knowledge Base

This folder serves as a centralized reference for high-quality problem sets, conceptual breakdowns, key equations, and worked example templates across various STEM fields. It is intended to be used as a "ground truth" well of material to continually expand the CIR app's assessment YAML files.

Because of the massive scope of this expansion, the knowledge base has been split into domain-specific documents. Please reference the individual documents below:

## 1. Mathematics
**File:** [`calculus.md`](calculus.md)
- **Calculus 2**: Integration by Parts, Trig Substitution, Partial Fractions, Series Convergence Tests, Taylor/Maclaurin Series, Parametric/Polar coordinates.
- **Calculus 3**: Vectors, Partial Derivatives, Gradients, Optimization (Lagrange), Multiple Integrals, Vector Calculus (Green's, Stokes', Divergence Theorems).

## 2. Physics
**File:** [`physics.md`](physics.md)
- **Physics 1**: Kinematics, Dynamics, Work/Energy, Momentum/Collisions, Rotational Motion, Gravitation.
- **Physics 2**: Electrostatics (Gauss's Law), Capacitance, Magnetism (Ampere's/Biot-Savart), Induction (Faraday), Thermodynamics (First Law, Carnot Engines).
- **Intro Quantum Physics**: Wave-Particle Duality, Photoelectric Effect, De Broglie, Schrödinger Equation, Particle in a Box, Heisenberg Uncertainty.

## 3. Chemistry
**File:** [`chemistry.md`](chemistry.md)
- **General Chemistry 1**: Atomic Structure, Periodicity, Stoichiometry, Gas Laws, Thermochemistry.
- **Qualitative Analysis**: Solubility Rules, Flame Tests, Complex Ion Formation, Precipitation Reactions.

## 4. Electrical & Computer Engineering
**File:** [`engineering.md`](engineering.md)
- **Circuit Theory**: Kirchhoff's Laws, Thevenin/Norton Equivalents, Transient Analysis, AC Steady-State (Phasors, Impedance).
- **Digital Signal Processing**: Discrete-Time Signals, Z-Transforms, ROC, DTFT, Digital Filters (FIR/IIR).
- **Computer Hardware**: Boolean Algebra, Combinational/Sequential Logic, CPU Architecture, Pipelining, Memory Hierarchy (Caches/AMAT).

## 5. Biology
**File:** [`biology.md`](biology.md)
- **Anatomy & Physiology**: Comprehensive coverage of the Skeletal, Muscular, Nervous, Endocrine, Cardiovascular, Respiratory, Digestive, Urinary, Lymphatic, and Reproductive systems.
