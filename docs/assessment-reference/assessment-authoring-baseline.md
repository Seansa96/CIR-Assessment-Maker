# Assessment Authoring Contract Baseline

Baseline status: catalog audit is report-only for legacy content. Category profiles are now declared for every category; existing assessments remain usable until they are created or materially modified through the repository save path.

Priority repair order:

1. Assessments missing schema-valid answers, media paths, or singular topic placement.
2. STEM lessons with fewer than seven active sections or missing checks.
3. Worked examples with fewer than two distinct problems or weak procedural coverage.
4. Quizzes/tests that need authoring metadata, default attempt counts, question-type balance, or source-grounded blueprint provenance.

Run the content audit and the authoring-contract test suite after each repair batch. The contract audit intentionally reports legacy deviations rather than making the existing catalog unloadable.
