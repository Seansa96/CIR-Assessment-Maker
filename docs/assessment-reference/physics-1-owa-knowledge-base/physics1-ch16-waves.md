# Chapter 16: Waves

Source guide: OpenStax *University Physics Volume 1* §§16.1--16.3 and §§16.5--16.6
(CC BY 4.0). Section 16.4 is intentionally not a separate topic in the requested
course scope.

## Curriculum outline

1. **Traveling waves:** transverse and longitudinal disturbances, amplitude,
   wavelength, period, frequency, and propagation direction.
2. **Mathematics of waves:** $y(x,t)$, phase, $k$, $\omega$, derivatives, and the
   linear wave equation.
3. **Stretched strings:** derive $v=\sqrt{T/\mu}$ from a small string element.
4. **Interference:** superposition, phase difference, constructive/destructive
   interference, and pulses.
5. **Standing waves and resonance:** reflection, nodes/antinodes, boundary
   conditions, harmonics, and resonant frequencies.

## Required derivation examples

Show the wave-function parameter relationships, derive the stretched-string speed,
and derive normal-mode frequencies from boundary conditions.

## Media requirements

Use wave snapshots, displacement-versus-position/time plots, a tensioned-string
element, pulse-overlap diagrams, and normal-mode diagrams with labeled nodes.
