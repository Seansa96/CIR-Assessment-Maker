# Physics I: Oscillations, Waves, and Acoustics

This local knowledge base is an original instructional guide derived from the section
outlines, learning objectives, equations, and figure ideas in OpenStax *University
Physics Volume 1*, Chapters 15--17 (CC BY 4.0). It is a guide for original CIR
lessons and questions; it is not a copy of the reference text.

## Scope

- Chapter 15: six oscillation topics.
- Chapter 16: traveling waves, wave mathematics, stretched-string speed,
  interference, and standing waves/resonance. Section 16.4 is not a standalone
  topic in this course scope.
- Chapter 17: eight sound/acoustics topics.

Every authored lesson and worked example requires a labeled original diagram and
accessible alt text. Each quiz and test has at least five diagram-based numerical
analysis questions.
